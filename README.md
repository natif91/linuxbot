# LinuxBot

Recomendador de distribuciones Linux para un trabajo práctico de Sistemas Operativos.

## Archivos
- `index.html`: estructura de la aplicación.
- `styles.css`: estilos adaptables.
- `script.js`: árbol de decisiones y fichas de recomendación.

## Publicación en GitHub Pages
Subir los archivos de esta carpeta a la raíz del repositorio y configurar **Settings → Pages → Deploy from a branch → main → /(root)**.

## Nota
Los requisitos de hardware son orientativos y pueden variar según la versión de cada distribución y las aplicaciones utilizadas. Consultar siempre la documentación oficial.
